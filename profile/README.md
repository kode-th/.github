# kode.th

Small, independent tools and APIs, built in Thailand by one developer.

## Products

- [สาระรัฐ (Sararath)](https://sararath.fasu.dev): an independent, read-only index of Thai government news. Not a government website.
- Planguin (in development): a calm daily planner for students who work. Classes, shifts, pay, bills and reminders on one timeline.
- SPIKE/LINE (paused): Valorant esports without the noise. Live scores, schedules, match stats and news. Live data is offline until the service has funding.
- Weather API: a free weather and geocoding API with the OpenWeather response shape. No API key needed.
